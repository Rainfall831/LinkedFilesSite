Know where your Blender assets are used.

LinkedFiles is a desktop app for Blender creators. Pick an asset, point it at a folder of .blend projects, and see every project and connection that references that file — locally on your machine.

Download for Windows

What LinkedFiles does

It answers one question: which Blender projects are using this file, and where inside each project is it linked?

How it works

  1. Select an asset (texture, model, or other file).
  2. Choose the folder where your Blender projects live.
  3. Scan projects to build or refresh a local index.
  4. See every project that uses the asset.
  5. Open the connection path: objects, materials, and nodes.

Desktop advantages

Projects stay on your computer. Indexing and search run locally so you can work with large libraries without uploading files.
