Early access

Know where your Blender assets are used.

LinkedFiles is a Windows desktop app in early access for Blender creators. Move or delete an image without breaking project links, relink missing files, and see which saved .blend projects use the image you select.

Free Download

Windows 10/11 (64-bit)

Windows 10/11 (64-bit). Blender installed (tested with 4.0, 4.2 and 5.2). Blender does not need to be open. If Windows blocks the installer, choose More info, then Run anyway.

What LinkedFiles does

  • Move an image and update paths in the Blender projects that reference it.
  • Relink missing files when a project still expects an image that was moved, renamed, or deleted.
  • Search one folder, or press Not sure to search every drive on the PC.
  • Delete an image to the Windows Recycle Bin after seeing which projects use it, with a Move It Instead option.
  • Preview every path edit first. LinkedFiles backs up each .blend and Undo restores the original.
  • Show where each project uses the image: object, then material, world, compositor, or geometry nodes, then the node.

How it works

  1. Select an image (texture, HDR, image sequence, UDIM tile, or movie file used as an image).
  2. Choose the folder where your Blender projects live, or press Not sure to search the whole PC. A whole-PC search is slower, and the app warns you first.
  3. Run Find Usage. Each search re-reads projects that changed since last time.
  4. Read results on the Used, Possible, and Missing tabs.
  5. Open a project to see where the image is used: object, material, world, compositor, or geometry nodes, then the node.
  6. Use Move Asset, Relink, or Delete Asset. Path edits wait for a preview, then update only the path bytes, with a backup and Undo.

Desktop advantages

Projects stay on your computer. Search runs locally. Project files, names, and paths are not uploaded.

System requirements

  • Windows 10 or later (64-bit)
  • Blender installed (tested with 4.0, 4.2 and 5.2). Blender does not need to be open.
  • Enough disk space for a local project index (size depends on your library)
  • Read access to folders that contain your .blend files

Supported assets

Trace image files used in Blender: textures, HDRs, image sequences, UDIM tiles, and movie files used as images (PNG, JPG, EXR, HDR, TGA, WEBP, PSD, DDS, and more). Matches can be by path, by file contents, or by file name. Results show the project, then where the image is used: object, material, world, compositor, or geometry nodes, and the node.

Limits

LinkedFiles searches for one selected image at a time. It reads saved .blend projects with your installed Blender in the background. Move Asset and Relink update path bytes in projects that reference the file, after a preview and a backup. A search with no results is not proof that a file is unused. Packed images, unsaved work, and files used outside Blender can be invisible to that search.
