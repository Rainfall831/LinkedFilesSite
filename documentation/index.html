Getting Started

  1. Install Blender (tested with 4.0, 4.2 and 5.2) and a LinkedFiles early access build on Windows.
  2. Open LinkedFiles. It finds a standard Blender install on its own.
  3. Select an image to trace.
  4. Select your Blender project folder, or press Not sure to search every drive on the PC. A whole-PC search is slower, and the app warns you first.
  5. Run Find Usage.

Blender Setup

LinkedFiles reads .blend files with your installed Blender in the background, including nested subfolders. Blender does not need to be open. Save projects before scanning so the latest file links are detected. Only saved changes are found.

If Blender is installed somewhere unusual, choose blender.exe from the Blender button at the top right. For faster scans, close Blender while LinkedFiles searches. Unsaved changes in open files do not appear until you save and search again.

Searching

A local cache makes repeat searches fast. Every search automatically re-reads projects that changed since last time. Save projects in Blender first. There is no separate refresh step.

LinkedFiles matches an image by path, by file contents (so a renamed or moved copy can still match), and by file name. File-name matches are listed as Possible.

Results

Projects are grouped with thumbnails. Tabs split the list into Used, Possible, and Missing.

Expand a project to see where the image is used:

  • Object: the object that uses the image
  • Material, world, compositor, or geometry nodes: the data-block that holds the image
  • Node: the node that references the image

Moving assets

Move Asset moves the selected image to another folder and updates the paths in every known project that uses it. Known projects are the ones from the last search plus ones already in the local index.

If a project cannot be updated, you choose: cancel and put everything back, or skip that project. Projects outside the searched folder are not updated unless they are already indexed. The app can suggest Search Whole PC First.

Close the project in Blender before moving it. If you save that project in Blender afterwards, Blender can write the old paths back.

Fixing missing files (Relink)

The Missing tab lists projects whose referenced files were moved, renamed, or deleted. Find Replacement… suggests matching files, ranked high, medium, or low confidence, or lets you browse. Relink Missing fixes all of a project’s missing files at once. Relink Assets… in a row’s ⋯ menu can relink a whole folder.

Relinking edits the .blend paths directly, without opening Blender. Images, sounds, fonts, movie clips, linked .blend libraries, volumes, and cache files can be relinked. Packed files, and data linked from another library, cannot.

Close the project in Blender before relinking, or saving it in Blender afterwards writes the old paths back.

Deleting assets

Delete Asset lists which projects use the file, then sends it to the Windows Recycle Bin. Those projects would lose the file. You can choose Move It Instead.

Backups and Undo

Relink and Move show a preview first. Nothing changes until you confirm. LinkedFiles writes a verified backup of each .blend before changing it, edits only the path bytes, then checks the result. When Blender is installed, it can re-check the file. Undo restores the exact original.

Backups are stored in %LOCALAPPDATA%\com.linkedfiles.app\backups\. A compressed .blend is saved uncompressed. Blender recompresses it the next time you save that project.

Project Index

The index is a local cache of project references so later searches stay fast. It stays on your computer. Each search re-reads projects that changed. You do not rebuild or refresh it by hand. Save projects in Blender before you search.

System requirements

  • Windows 10 or later (64-bit)
  • Blender installed (tested with 4.0, 4.2 and 5.2). Blender does not need to be open.
  • Read and write access to the folders you search
  • Image files used in Blender, including PNG, JPG, EXR, HDR, TGA, WEBP, PSD, DDS, image sequences, UDIM tiles, and movie files used as images

Limitations

LinkedFiles searches for one selected image at a time. It reads saved .blend projects with your installed Blender in the background. Move Asset and Relink edit path bytes in those projects, after a preview and a backup. It does not produce a library-wide list of every unused file.

A search with no results is not proof that a file is unused. The image may be packed into a .blend file, the project may be unsaved, or the file may be used by software other than Blender.

Troubleshooting

  • Blender not detected: Install Blender from blender.org, or choose blender.exe from the Blender button if it is installed somewhere unusual.
  • Project scan errors: Check file permissions and that projects are not locked by another app. Close the project in Blender before a relink or move.
  • Missing files: Open the Missing tab. Find Replacement, Relink Missing, or Relink Assets can point the project at the file again.
  • Unsupported files: Search traces image files. Materials, objects, and nodes appear only as where an image is used.
  • Search returning no results: Save the project in Blender first. LinkedFiles can match by path, file contents, or file name. Packed images and unsaved work will not match the file on disk.
