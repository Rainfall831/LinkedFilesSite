Frequently asked questions

Can I move an asset without breaking Blender projects?
Yes. After you scan, use Move Asset in LinkedFiles. The app moves the file on disk and updates paths in the .blend projects that reference it, so you can reorganize your library without broken texture links.
What does LinkedFiles do?
LinkedFiles finds which Blender projects use an image you select, such as a texture, HDR, image sequence, or UDIM tile, and shows where it is used. You can move or delete that image, or relink missing files, without breaking those projects.
Do I need Blender open while searching?
Blender must be installed (tested with 4.0, 4.2 and 5.2), but it does not need to be open. LinkedFiles reads .blend files with your installed Blender in the background. Save projects before scanning so the latest links are included. Closing Blender can make scans faster.
Does LinkedFiles upload my Blender projects?
No. Project files, file names, paths, project names, and search results are never uploaded. The app sends anonymous usage statistics to PostHog (US servers). These are on by default, explained on first launch with OK or Turn Off, and can be switched any time with Share anonymous usage stats in the Blender menu.
Does LinkedFiles edit my .blend files?
Search reads projects with your installed Blender in the background and stores a local index. Move Asset and Relink update path bytes in .blend files only after you confirm a preview. Each project is backed up first, and Undo restores the original.
Can LinkedFiles find which projects use a texture?
Yes. Select a texture, HDR, or other external file, then scan a folder of Blender projects. Results list the .blend files that reference it, with object, material, and node paths when those are available.
What should I do after I change a project or asset?
Save the project in Blender first. The next search automatically re-reads projects that changed since last time. There is no separate refresh step.
Can LinkedFiles fix missing textures?
Yes. The Missing tab lists projects whose referenced files were moved, renamed, or deleted. Find Replacement suggests matching files, Relink Missing fixes all of a project's missing files at once, and Relink Assets can relink a whole folder. Relinking edits the .blend paths without opening Blender.
Is moving or relinking safe?
Yes. Nothing changes until you confirm a preview. LinkedFiles saves a verified backup of each .blend, changes only the path bytes, checks the result, and Undo restores the exact original. Close the project in Blender first so a later save does not write the old paths back.
Does a search with no results mean I can delete the file?
No. No results means LinkedFiles did not find a reference in the .blend files it scanned. The file can still be packed inside a project, referenced by unsaved work, or used outside Blender.
Why not just search my folders manually?
A folder search shows where a filename exists on disk. LinkedFiles shows which Blender projects reference that file, so you do not have to open each project.
What happens if I move or rename an asset?
Use Move Asset in LinkedFiles to move the file and update paths in the projects that reference it. If you move or rename a file outside the app, scan again to see which projects still point at the old location.
Who is LinkedFiles for?
Blender artists, 3D modelers, freelancers, and studios who need to see which projects use a given file.
Can I use LinkedFiles with a large asset library?
Yes. It is a Windows desktop app meant to scan folders that contain many Blender projects. The index stays on your machine.
Is LinkedFiles in early access?
Yes. LinkedFiles is a Windows desktop app in early access. Features and performance may change.
