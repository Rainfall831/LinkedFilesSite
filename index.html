Frequently asked questions

What does LinkedFiles do?
LinkedFiles scans folders of .blend projects on your PC and shows which files reference an asset you choose, including materials, textures, models, and node links.
Do I need Blender open while searching?
No. LinkedFiles reads .blend files directly. Save projects before scanning so the latest links are included. Closing Blender can make scans faster.
Does LinkedFiles upload my Blender projects?
No. Indexing and search run on your computer. Normal use does not upload your project files or asset library.
Does LinkedFiles edit my .blend files?
The app reads .blend files and stores a search index on your computer. The public documentation does not describe editing or rewriting your projects.
Can LinkedFiles find which projects use a texture?
Yes. Select a texture, HDR, or other external file, then scan a folder of Blender projects. Results list the .blend files that reference it, with object, material, and node paths when those are available.
What should I do after I change a project or asset?
Refresh the index. Later searches use the local index, so new or edited projects are not included until you scan again.
Does a search with no results mean I can delete the file?
No. No results means LinkedFiles did not find a reference in the .blend files it scanned. The file can still be packed inside a project, referenced by unsaved work, or used outside Blender.
Why not just search my folders manually?
A folder search shows where a filename exists on disk. LinkedFiles shows which Blender projects reference that file, so you do not have to open each project.
What happens if I move or rename an asset?
LinkedFiles can list the Blender projects that reference the file, so you can see what may break before you change it. It does not rewrite those project paths for you.
Who is LinkedFiles for?
Blender artists, 3D modelers, freelancers, and studios who need to see which projects use a given file.
Can I use LinkedFiles with a large asset library?
Yes. It is a Windows desktop app meant to scan folders that contain many Blender projects. The index stays on your machine.
Is LinkedFiles in early access?
Yes. LinkedFiles is a Windows desktop app in early access. Features and performance may change.
