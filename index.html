Frequently asked questions

What does LinkedFiles do?
It scans folders of .blend projects on your PC and shows which files reference an asset you choose: materials, textures, models, and node links included.
Do I need Blender open while searching?
No. LinkedFiles reads project files directly. Closing Blender can speed up scans; save projects first so the latest links are detected.
Is LinkedFiles in early access?
Yes. LinkedFiles is a Windows desktop app in early access. Features and performance may change as we iterate with testers.
Why not just search my folders manually?
A normal file search can tell you where a file exists. LinkedFiles tells you which Blender projects actually use that file, saving you from opening projects one by one.
What happens if I move or rename an asset?
LinkedFiles can help you identify the Blender projects that reference the asset so you can understand what may be affected before making changes.
Who is LinkedFiles for?
LinkedFiles is useful for Blender artists, 3D modelers, game developers, studios, freelancers, and anyone managing large collections of Blender projects and assets.
Can I use LinkedFiles with a large asset library?
Yes. The desktop application is intended for scanning folders containing multiple Blender projects and assets.
