Privacy Policy

Website

This marketing site is static. It does not run analytics, advertising trackers, or cookie banners in the current implementation. If you use the contact form, messages are not sent to a server until backend email is configured.

Standard web server logs (if any) from your host may include IP address and browser type — check your hosting provider’s policy.

Desktop app

LinkedFiles is designed to read Blender project files locally on your computer. Project content is not uploaded to LinkedFiles servers as part of normal indexing and search described on this site.

Local index data is stored on your device. Future versions may offer optional cloud features; those will be documented separately if added.
