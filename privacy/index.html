Privacy Policy

Last updated: October 3, 2026

This policy explains what information LinkedFiles collects when you use this website and the LinkedFiles desktop application.

Website

This marketing site is static HTML and CSS. It does not use advertising trackers or third-party analytics in the current implementation.

If you host the site with a third-party provider, that provider may log IP addresses, request URLs, and browser identifiers in server logs. Refer to your host’s privacy documentation for details.

Contact requests sent through the Contact page or by email are handled by LinkedFiles. We use your message only to respond to your request.

Desktop application

LinkedFiles is designed to read Blender project files on your computer and build a local search index. Normal use does not upload your project files or asset library to LinkedFiles servers.

Index data is stored on your device. You can delete the index by removing the application data folder or using in-app controls when available.

If we add optional online features in the future (for example, account sync or crash reporting), we will update this page and describe what is collected before those features ship.

Children’s privacy

LinkedFiles is not directed at children under 13. We do not knowingly collect personal information from children.

Changes

We may update this policy from time to time. The “Last updated” date at the top of this page will change when we do.

Contact

Privacy questions: Contact us.
